# 카카오 T(택시) 앱 리뷰 분석 및 개선안

## 1. 개요
- 분석 대상: 리뷰 76개
- 별점: 1점이 압도적으로 많습니다. 5점은 3개이고, 그중 2개는 내용이 단순한 칭찬이거나 기능 제안입니다. 66번은 별점 1점에 "11점 드립니다"라고 쓴 반어적 리뷰로 보입니다.
- 리뷰는 아래 5개 주제에 몰려 있습니다. 많이 언급된 순서입니다.

## 2. 핵심 이슈 (빈도·심각도 순)

### A. 블루 파트너스 유도와 일반 호출 불만 (약 20건 이상)
- 해당 리뷰 번호: 1, 3, 4, 10, 12, 19, 45, 51, 72, 80, 82, 83, 87, 97, 99 등
- 일반 호출은 잡히지 않고 유료(+1,500~5,000원) 블루만 바로 잡힌다는 불만이 많습니다. "일부러 일반콜을 기사에게 전달하지 않는다"는 의혹도 여러 건 있습니다.
- 블루가 목록 맨 위에 노출됩니다. 일반 택시를 눌렀는데 이용료가 추가되어 있었다는 불만도 있어 다크패턴 인식이 강합니다.
- 블루인데도 다른 손님을 태우고 운행 중인 차(백투백)가 배차되어 15~30분씩 늦게 도착합니다. 무료 취소가 가능하다는 사실은 문의해야 알 수 있습니다.
- 7년 이상 쓴 장기 이용자의 이탈 선언이 나옵니다(83번). 경쟁 앱으로 우버, DD, 타 택시 앱이 거론됩니다.

### B. 배차 실패, 지연, 먼 택시 배차, 기사 취소 (약 20건)
- 해당 리뷰 번호: 7, 8, 22, 26, 32, 35, 37, 42, 62, 75, 83, 84, 86, 91, 1, 15 등
- 30분~1시간 동안 배차가 안 됩니다. 도착 예정 시간이 4분에서 12분으로 바뀌고, 멀리 있는 택시가 배차되기도 합니다.
- 기사가 일방적으로 취소합니다. 도착 1~2분 전에 취소하는 경우도 있지만 기사에게 불이익이 없어 보입니다.
- 이용자는 1분 뒤 취소하면 패널티를 받고, 먼 택시를 거절해도 24시간 정지됩니다(67번). 이런 비대칭에 불만이 큽니다.
- 기사 취소 후에도 수수료를 물거나 환불이 안 된다는 불만이 있습니다(73번).

### C. 추천 경로의 신뢰 문제 (약 20건)
- 해당 리뷰 번호: 2, 6, 21, 29, 31, 33, 41, 44, 47, 49, 50, 65, 81, 88, 93, 95 등
- 더 빠르고 가까운 길이 있는데 막히거나 돌아가는 경로를 추천합니다. 이 때문에 요금이 1천~1만 원 더 나온다고 합니다.
- "요금이 더 나오게 하려는 것 아니냐"는 불신이 크고, 가장 먼 경로를 가장 싼 것처럼 표시한다는 지적도 있습니다.
- 이용자가 경로를 직접 선택하거나 지정할 수 없습니다. 기사에게 말해도 "정해진 길로 가야 한다"는 답이 돌아옵니다. 기사는 앱 경로를 따르지 않으면 패널티를 받는다고 합니다(95번).
- 공사 구간이 반영되지 않고, 출발지와 도착지 안내가 기사 앱과 달라(다리 위/아래, 48·49번) 오배차나 오도착이 생깁니다.
- 요금 불투명성도 문제입니다. 예상 요금보다 실제 요금이 항상 높고, 처음 표시한 금액으로 결제되는 방식은 없습니다(44번).

### D. 위치와 출발지 오류 (약 8건)
- 해당 리뷰 번호: 8, 9, 35, 65, 68, 69, 89, 96 등
- GPS가 부정확합니다. 출발지를 바꿔도 승차 위치가 갱신되지 않고, 앱이 출발지를 임의로 바꿉니다. 도로 반대편으로 배차되어 U턴해야 하는 경우도 있습니다.
- 지도에서 장소 명칭을 알아보기 어렵다는 의견도 있습니다.

### E. 계정, 결제, 고객센터 문제
- 로그인이 풀립니다(13번). 반대로 로그아웃 메뉴가 없다는 의견도 있습니다(40번). 인증번호가 오지 않습니다(38번).
- 이중 결제를 해결해 주지 않습니다(92번).
- 약관을 바꿔 월정액이 적용되지 않았고 사전 고지도 없었다는 불만이 있습니다(53번).
- 주차패스를 취소할 수 없어 결제되었고 환불도 거절당했습니다(54번).
- 퀵 서비스에서는 기사가 취소하고 요금 손해는 고객이 지며, 문의 답변이 보름 넘게 없습니다(55번).
- 고객센터가 "유의사항에 있다"는 이유로 책임을 회피하거나 전화를 끊는다는 불만이 반복됩니다(48, 53, 54, 95번).

### F. 기능 요청 (소수지만 구체적)
- 전기차 제외 옵션(59, 90번). 멀미가 이유입니다.
- 운행 중인 택시 제외 옵션(19, 82번).
- 기사 취소 시 해당 기사를 차단하는 기능(84번).
- 탑승 상태에서도 기사에게 전화할 수 있는 버튼(70번). 다른 사람이 택시를 잘못 탄 경우를 대비한 것입니다.
- 승차 거부 신고를 결제 전에도 할 수 있게 해달라는 요청(71번).
- 도착지를 사전에 기사에게 공개해 달라는 요청(71번).
- 기사 선호 설정(조용히 가기, 반려동물 동승 등, 74번).
- 평가 팝업을 끄거나 건너뛰는 기능(43번).
- 시외 콜에서 기사가 회피하지 않도록 매칭을 개선해 달라는 요청(63번).
- 반납 상태가 업데이트되지 않는 문제(98번). 이는 택시가 아닌 다른 서비스 이슈로 보입니다.

## 3. 개선안

### 우선순위 1 (즉시, 신뢰 회복)
1. **블루 UI 투명화**
   - 일반과 블루를 같은 비중으로 나란히 보여주고, 추가 요금을 호출 전 화면에 명확히 표시합니다.
   - 일반 택시를 눌렀을 때 요금이 임의로 추가되지 않도록 기본 선택값과 화면 순서를 점검합니다.
   - 일반 호출 성공률과 평균 대기 시간을 블루와 함께 공개하고 내부 모니터링합니다. 일반 콜이 의도적으로 후순위가 되고 있다면 중단합니다.
2. **백투백(운행 중) 배차 제어**
   - 유료 블루에는 운행 중인 택시를 배차하지 않거나, 배차할 경우 "현재 운행 중, 예상 N분" 문구와 무료 취소를 호출 시점에 자동으로 안내합니다.
   - "운행 중 택시 제외" 필터를 제공합니다.
3. **기사 취소 대응**
   - 기사 취소 시 이용자에게 수수료와 패널티를 면제하고, 즉시 재배차를 우선 처리합니다.
   - 기사 취소율이 높은 기사에게 패널티를 주고, 이용자가 특정 기사를 다시 배차받지 않도록 차단하는 기능을 추가합니다.
   - 이용자 취소 패널티 기준(1분, 배차 거절 시 24시간 정지)을 완화합니다. 특히 멀거나 ETA가 크게 늘어난 배차를 거절할 때는 패널티를 면제합니다.

### 우선순위 2 (핵심 품질)
4. **경로 추천 개선**
   - 기본 추천은 최단 시간 또는 최저 요금 기준으로 하고, 추천 기준(시간, 거리, 요금)을 라벨로 표시합니다.
   - 이용자가 경로를 선택하거나 경유지, 방향을 지정할 수 있게 합니다. 선택한 경로는 기사 앱에 그대로 전달하고, 기사 앱과 경로, 목적지가 일치하는지 검증합니다.
   - 공사 구간과 실시간 교통을 반영합니다. 경로 변경에 따른 요금 차이를 사전에 표시합니다.
   - 유도 의혹이 있으므로 요금이 높은 경로를 더 싸 보이게 표시하는 문구를 제거합니다.
   - 기사 경로 이탈에 대한 패널티 정책을 점검합니다. 앱 경로가 비합리적일 때 기사가 우회하거나 항의할 수 있는 절차를 마련합니다.
5. **요금 확정제 도입**
   - 호출 시 표시한 예상 금액을 기준으로 상한이나 확정 요금을 보장하는 옵션을 제공합니다. 경로를 바꿨을 때 요금 증가분 분쟁도 줄일 수 있습니다.
6. **배차 알고리즘 개선**
   - 거리와 ETA 기준을 엄격하게 적용하고, 오래 대기한 이용자에게 우선권을 줍니다(32번 요구).
   - ETA를 실시간으로 보정해 4분에서 12분으로 바뀌는 등의 오차를 줄입니다.
   - 도로 반대편 배차를 방지하기 위해 진행 방향과 차선을 반영합니다.
   - 비, 심야, 연휴(추석) 등 수요가 몰릴 때의 공급 대책을 마련합니다.
   - 시외 콜에서는 기사가 회피하지 않도록 인센티브 또는 매칭 방식을 개선합니다.
7. **위치 정확도 개선**
   - 출발지를 변경하면 승차 위치가 즉시 반영되는지 확인합니다. 앱이 출발지를 임의로 바꾸지 않도록 합니다.
   - 장소명 표시를 개선하고, 지도에서 승차 지점을 확인하고 핀을 조정할 수 있게 합니다.

### 우선순위 3 (계정, 결제, CS, 편의 기능)
8. **로그인, 인증**: 로그인 유지가 풀리는 원인을 수정합니다. 로그아웃 메뉴를 명확히 두고, 인증번호 발송 실패에 대응합니다.
9. **결제, 환불 정책**
   - 이중 결제는 시스템 기록으로 자동 확인해 환불하고, 영수증 제출을 요구하지 않습니다.
   - 주차패스 등 부가 상품에 취소 기능을 제공하고 결제 전 확인 단계를 둡니다.
   - 약관과 요금제를 변경할 때는 사전 고지(푸시, 이메일)와 동의 절차를 거칩니다.
10. **고객센터**
    - 응답 기한(SLA)을 정하고, 기사 귀책 사례는 환불을 기본으로 합니다. "유의사항에 안내됨"만을 이유로 거절하지 않습니다.
    - 퀵 등 다른 서비스의 문의 처리 지연을 개선합니다.
    - 기사 오배송과 오도착 사례에는 별도 신고 절차를 둡니다.
11. **기능 추가**
    - 전기차 제외 옵션.
    - 탑승 중에도 기사 통화 버튼 유지.
    - 결제 전에도 승차 거부 신고 가능.
    - 기사에게 도착지를 사전에 공개하되 개인정보를 보호하는 방식을 검토.
    - 반려동물과 조용한 이동 등 선호 옵션.
    - 평가 팝업 건너뛰기.
    - 펫택시 요금 재검토.

## 4. 측정 지표(KPI) 제안
- 일반 호출 성공률과 평균 배차 시간(블루와 비교)
- 기사 취소율과 이용자 취소 패널티 건수
- 추천 경로 대비 실제 주행 경로 및 요금 편차(예상 대비 실제 요금 차이)
- 블루 전환율과 블루 요금 관련 CS 건수
- 1점 리뷰 비중, 이탈 및 삭제 언급 건수, 환불 요청 처리 시간

## 5. 분석상 유의점
- 일부 주장, 예를 들어 "일반 콜을 기사에게 전달하지 않는다"는 이용자의 추정이며 사실 확인이 필요합니다. 다만 같은 주장이 반복되므로 내부 데이터로 검증하고, 결과를 공개하는 것이 신뢰 회복에 효과적입니다.
- 일부 리뷰는 앱 문제와 무관하거나 모호합니다(23, 28, 30, 64, 66번 등). 그래서 핵심 이슈 집계에서는 제외하거나 가중치를 낮췄습니다.
- 리뷰 수가 76개로 적은 편이어서 비율은 대략적인 경향으로만 보셔야 합니다.
