## 1. 요약
- 가장 많이 지적된 문제는 배차 지연·지역 편차(관련 리뷰 7개)입니다. 그다음은 고객센터 대응 부실(6개)과 카드 등록·가입 절차 오류(6개)입니다.
- 취소 때 수수료가 붙거나 취소가 안 되는 문제(5개), 길안내·픽업 위치 오류(5개), 기사 연락 불가·분실물(5개)도 반복됩니다. 이중 결제·예상요금 문제는 3개입니다.
- 돈을 더 냈다고 말한 리뷰는 취소 수수료(5, 12, 31), 이중 결제(27, 32), 환불·답변 거부(27, 28, 50)에서 나왔습니다. 카드 등록이 안 돼 앱을 지웠다는 리뷰는 25번입니다.

## 2. 카테고리별 문제점
### 배차 지연·지역 편차 (관련 리뷰 7개)
- 호출해도 기사가 잘 안 잡힙니다. (14, 17, 20)
- 서울 외 지역은 거의 잡히지 않습니다. (47)
- 스피드·우선 호출을 써도 소용이 없고, 먼 차량이 배정돼 대기 시간이 길어집니다. (4, 20, 57, 51)
- 대표 리뷰: "10번 부르면 1번 응답이 올까말까"(17). "우선 호출로 20분을 기다렸다"(20). "스피드호출 5분 기다리면 기사 9분 뒤 도착"(4).

### 호출 취소 절차·수수료 (관련 리뷰 5개)
- 취소 버튼이 숨겨져 있고, 사유를 선택한 뒤에도 되묻는 단계가 많습니다. (1, 31)
- 취소할 때 오류가 나서 배차 뒤에야 취소되고, 수수료가 부과됩니다. (5)
- 기사가 배정되지 않았는데도 취소하면 결제가 됩니다. (12)
- 배차 지연으로 취소해도 수수료를 내야 합니다. (57)
- 대표 리뷰: "취소 때 에러가 나서 배차 후 취소됐고 수수료 2000원이 빠졌다"(5). "기사도 안 잡혔는데 취소하면 결제가 된다"(12).

### 길안내·픽업 위치 오류 (관련 리뷰 5개)
- 네비게이션이 돌아가는 길, 막히는 길, 통제 도로로 안내하고 경로 옵션도 없습니다. (4, 33, 46, 56)
- GPS와 픽업 위치가 틀려 기사가 반대 방향에서 오고, 위치를 정정할 방법이 없습니다. (4, 56)
- 호출 장소 표기가 다르게 뜹니다. (23)
- 대표 리뷰: "항상 돌아가는 길로 안내한다. 옵션이 필요하다"(56). "GPS가 꾸준히 잘못 찍히고 정정이 안 된다"(4).

### 고객센터 대응 부실 (관련 리뷰 6개)
- 승객용 전화·채팅 채널이 없거나 답변이 없습니다. (9, 26, 28, 50)
- 문의를 종료 처리하거나 추가 입력을 막아 재문의가 안 됩니다. (9, 27)
- 운행 상태 오류로 호출이 막혀도 승객이 직접 해결할 수 없고, 보상도 없습니다. (3, 26)
- 대표 리뷰: "영수증을 보냈는데 대화창이 닫혀 추가 문의를 못 했고 결국 1600엔을 더 냈다"(27). "기사가 운행완료를 안 눌러 새 호출이 막혔다"(26).

### 기사 연락·분실물 대응 (관련 리뷰 5개)
- 하차 뒤 기사에게 연락할 수 없어 분실물 문의가 막힙니다. (6, 42, 56)
- 기사 전화가 다른 사람에게 연결되거나 없는 번호로 나옵니다. (26, 56)
- 기사 전화가 국제전화로 와서 불안합니다. (4)
- 대표 리뷰: "중요한 분실물인데 기사가 연락을 차단했고 고객센터는 1시간 넘게 전화를 안 받았다"(42).

### 결제·요금 오류 (관련 리뷰 3개)
- 현장 결제 후 결제 미처리로 이용이 정지되고 이중 결제가 일어납니다. (27)
- 기사의 착오 결제로 이중 결제와 가승인이 걸리고 취소가 안 됩니다. (32)
- 예상 요금보다 1~2천 원 더 나와 예상 요금을 믿기 어렵습니다. (30)
- 대표 리뷰: "영수증까지 있는데 미결제로 처리돼 1600엔을 더 냈다"(27). "다른 카드로 24800원이 이중 결제됐다"(32).

### 카드 등록·가입 절차 오류 (관련 리뷰 6개)
- 카드 등록이 계속 실패하는데 이유를 알려주지 않습니다. (58, 62)
- 결제수단 등록이 필수여서 앱을 삭제했습니다. (25)
- 생년월일 입력창의 글자가 검은색이라 화면과 구분되지 않습니다. (57)
- 동의 화면에서 '모두 동의'만 눌리고 선택 항목은 체크할 수 없습니다. (54, 55)
- 대표 리뷰: "처음 출시 때나 지금이나 카드 등록이 안 되는데 이유를 모른다"(62). "광고 동의는 선택이라면서 모두 동의 말고는 버튼이 안 눌린다"(54).

## 3. 개선안 우선순위

영향이 큰 문제 중 빨리 해결할 수 있는 것부터 순위를 매겼습니다. (① 바로 실행 → ② 중장기 과제 → ③ 여유 있을 때 → ④ 보류)

| 순위 | 개선안 | 구분 | 근거 리뷰 수 |
|---|---|---|---|
| 1 | 취소 버튼 노출·오류 수정과 무과실 취소 수수료 면제 | ① 바로 실행 | 5 |
| 2 | 원거리 배차 제한과 도착 예상시간 보정 | ① 바로 실행 | 7 |
| 3 | 카드 등록 실패 사유 안내와 입력창 가독성 개선 | ① 바로 실행 | 4 |
| 4 | 하차 후에도 쓸 수 있는 기사 연락·분실물 문의 기능 | ① 바로 실행 | 5 |
| 5 | 승객 문의 재개·답변기한 보장과 운행 상태 오류 해소 | ② 중장기 과제 | 6 |
| 6 | 경로 선택 옵션과 픽업 위치 수정 기능 추가 | ② 중장기 과제 | 5 |
| 7 | 동의 화면에서 선택 항목 개별 체크 허용 | ③ 여유 있을 때 | 2 |
| 8 | 이중 결제·가승인 자동 검증과 환불 | ④ 보류 | 2 |

<sub>영향 큼: 근거 리뷰가 분석 대상(45개)의 10% 이상, 또는 심각도 상이면서 5% 이상. 빨리 해결: 난이도 하·중. 같은 구분 안에서는 근거 리뷰 수 × 심각도(상 3, 중 2, 하 1) 순.</sub>

### 1. 취소 버튼 노출·오류 수정과 무과실 취소 수수료 면제
① 바로 실행 · 심각도 상 · 난이도 중
- **개선 방법**: 호출 화면에 취소 버튼을 눈에 띄게 두고, 사유를 선택하면 바로 취소되게 합니다. 취소 오류 때문에 늦어진 취소와 기사 미배정 상태의 취소에는 수수료와 결제를 걸지 않습니다. ETA가 크게 늘어난 경우에도 무료 취소를 허용합니다.
- **기대 효과**: 취소 수수료와 결제 불만이 줄고, 취소가 안 돼 택시가 오는 일이 줄어듭니다. 확인 지표는 취소 오류율과 취소 수수료 문의 건수입니다.
- **근거 리뷰**: 1, 5, 12, 31, 57

### 2. 원거리 배차 제한과 도착 예상시간 보정
① 바로 실행 · 심각도 중 · 난이도 중
- **개선 방법**: 스피드·우선 호출에서는 예상 도착시간이 일정 시간을 넘는 차량을 배정하지 않고 재배차합니다. 표시 ETA를 실제 이동 시간으로 보정하고, 배차가 길어지면 재탐색 중임을 알립니다. 지역별 호출 응답률을 모니터링합니다.
- **기대 효과**: 배차 대기와 '안 잡힘' 불만이 줄어듭니다. 확인 지표는 호출 응답률, 평균 배차 대기시간, ETA 오차입니다.
- **근거 리뷰**: 4, 14, 17, 20, 47, 51, 57

### 3. 카드 등록 실패 사유 안내와 입력창 가독성 개선
① 바로 실행 · 심각도 상 · 난이도 중
- **개선 방법**: 카드 등록이 실패하면 사유(정보 오류, 인증 실패 등)와 해결 방법을 보여 줍니다. 생년월일 입력창의 글자색과 대비를 고칩니다. 등록 전에도 이용 흐름을 미리 볼 수 있게 해 등록 단계에서 앱을 지우는 일을 줄입니다.
- **기대 효과**: 카드 등록 실패 불만과 가입 이탈이 줄어듭니다. 확인 지표는 카드 등록 성공률과 가입 완료율입니다.
- **근거 리뷰**: 25, 57, 58, 62

### 4. 하차 후에도 쓸 수 있는 기사 연락·분실물 문의 기능
① 바로 실행 · 심각도 중 · 난이도 중
- **개선 방법**: 앱 안에서 기사와 통화하거나 메시지를 주고받는 안심번호·채팅을 하차 후 일정 기간 유지합니다. 분실물 신고 버튼을 만들어 기사와 연결하고, 연결이 안 되면 고객센터로 넘깁니다. 번호가 없는 번호로 나오는 오류도 고칩니다.
- **기대 효과**: 분실물 연락 불가와 기사 통화 불안이 줄어듭니다. 확인 지표는 분실물 문의 해결 시간과 기사 연락 실패율입니다.
- **근거 리뷰**: 4, 6, 26, 42, 56

### 5. 승객 문의 재개·답변기한 보장과 운행 상태 오류 해소
② 중장기 과제 · 심각도 상 · 난이도 상
- **개선 방법**: 문의가 종료된 뒤에도 승객이 추가 메시지를 보낼 수 있게 하고, 결제 문의는 답변 기한을 정해 지킵니다. 승객용 전화·채팅 접수 경로를 마련합니다. 기사가 운행완료를 누르지 않아 호출이 막힐 때는 승객이 운행을 직접 종료할 수 있게 합니다.
- **기대 효과**: 무응답과 재문의 차단 불만이 줄고, 호출이 막히는 일도 줄어듭니다. 확인 지표는 문의 첫 응답시간, 재문의율, 운행 상태 오류 문의 건수입니다.
- **근거 리뷰**: 3, 9, 26, 27, 28, 50

### 6. 경로 선택 옵션과 픽업 위치 수정 기능 추가
② 중장기 과제 · 심각도 중 · 난이도 상
- **개선 방법**: 기사 네비게이션에 실시간 교통과 도로 통제를 반영하고, 최단·최소시간 같은 경로 옵션을 둡니다. 승객이 지도에서 픽업 핀을 직접 수정하고 장소명을 바르게 표시하게 합니다. 기사가 추천 경로를 벗어나도 불이익이 없도록 안내합니다.
- **기대 효과**: 우회와 잘못된 픽업 위치 불만이 줄어듭니다. 확인 지표는 픽업 지연 시간, 기사 통화 요청 빈도, 경로 관련 신고 건수입니다.
- **근거 리뷰**: 4, 23, 33, 46, 56

### 7. 동의 화면에서 선택 항목 개별 체크 허용
③ 여유 있을 때 · 심각도 중 · 난이도 하
- **개선 방법**: '모두 동의'만 눌리는 오류를 고쳐 필수와 선택 항목을 따로 체크할 수 있게 합니다. 선택 항목은 해제한 채로도 다음 단계로 넘어가게 합니다.
- **기대 효과**: 원하지 않는 광고 동의를 강요받는다는 불만이 사라집니다. 확인 지표는 선택 항목 개별 체크 비율입니다.
- **근거 리뷰**: 54, 55

### 8. 이중 결제·가승인 자동 검증과 환불
④ 보류 · 심각도 상 · 난이도 상
- **개선 방법**: 같은 운행에 결제가 두 번 이상 걸렸는지 자동으로 검사해 중복분을 환불하고 가승인을 해제합니다. 현장 결제 영수증을 앱에서 등록하면 미결제 이용정지를 풀어 줍니다.
- **기대 효과**: 이중 결제와 이용 정지 불만이 줄어듭니다. 확인 지표는 중복 결제 환불 건수와 결제 관련 문의율입니다.
- **근거 리뷰**: 27, 32

## 4. 기타 요청 (근거 리뷰 1개)

- 화면이 복잡하고 선명하지 않으니 UI를 개선해 주세요. (29)
- 기사 얼굴 사진을 도용한 사례가 있으니 기사 신원 인증 관리를 강화해 주세요. (18)
- 예상 요금이 실제 요금과 크게 달라 의미가 없으니 예상 요금 정확도를 높여 주세요. (30)
- 기사가 배차 후 승객에게 취소를 요청하면 시간만 날리므로, 기사 취소 요청에 사유 표시나 제한을 두고 승객에게 보상해 주세요. (48)
