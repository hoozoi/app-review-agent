## 1. 요약
- 가장 많이 지적된 문제는 '일반 호출 배차 실패·지연'(16개)입니다. 그다음은 '추천경로 문제'(14개), '블루 유도·추가요금'(13개)입니다.
- 일반 호출이 안 잡혀 블루(유료)로 가게 되고, 추천경로가 돌아가서 요금이 더 나온다는 불만이 이어집니다. 사용자는 돈과 시간을 더 쓴다고 느낍니다.
- 기사 취소, 이중결제, 환불 거부, 출발·도착지 오류, 로그인 문제도 있습니다. 이용 포기나 금전 피해로 이어진 사례가 있습니다.

## 2. 카테고리별 문제점
### 일반 호출 배차 실패·지연 (관련 리뷰 16개)
- 급할 때 호출이 오래 안 잡힘. 30분~1시간 대기 후 삭제하거나 지각함 (7, 32, 42, 62, 86, 91, 97)
- 가까운 택시 대신 멀거나 반대 방향의 택시가 배차됨. 도착 예정 시간도 크게 늘어남 (8, 9, 22, 35, 37, 65, 89)
- 지역·시간대별로 호출이 막힘. 강남, 시외, 장거리, 빈차가 있는데도 안 잡힘 (25, 63)
- 대표 리뷰: "서울권에서 30분동안 안잡히는거보고 삭제합니다"(42). "택시잡는데 1시간 기다린거는 처음"(32).

### 블루 유도·추가요금 (관련 리뷰 13개)
- 블루파트너스를 맨 위에 노출하고 일반 호출은 잘 안 잡히게 해서 추가요금을 내게 만든다는 불만 (3, 10, 12, 34, 45, 72, 80, 83, 99)
- 일반 택시를 눌렀는데 이용료 3천원이 추가되어 있었음 (4)
- 블루인데도 이미 운행 중인 택시가 배차되어 15~30분 늦게 옴 (19, 82, 87)
- 대표 리뷰: "일반 택시 눌렀는데 확인하면 이용료 3천원 추가되어있음"(4). "일반콜이 있는데도 블루콜로 유도해서 수수료 5천원"(80).

### 추천경로 문제 (관련 리뷰 14개)
- 빠른 길이 있는데 막히거나 돌아가는 길을 추천함. 시간과 요금이 늘어남 (2, 6, 21, 29, 50, 81, 88, 93, 95)
- 경로를 직접 선택하거나 지정할 수 없음. 기사에게 매번 설명해야 함 (31, 33, 47)
- 추천경로가 요금을 더 받으려는 것처럼 보이고, 예상금액보다 더 나옴. 가장 돌아가는 경로를 싸게 표시함 (33, 41, 44)
- 대표 리뷰: "15분이면 가는길을 추천경로로 막히는 길을 잡아 시간도 2배, 요금도 배"(50). "예상금액에 만원정도가 더 붙네요"(44).

### 기사 취소·환불·결제 분쟁 (관련 리뷰 10개)
- 기사가 배차를 일방적으로 취소하거나 도착 직전에 취소함. 사용자는 보상을 받지 못함 (1, 15, 26, 75, 84)
- 기사 잘못인데도 사용자가 수수료를 내고 환불은 거부됨. 백투백 배차인데도 환불이 어려움 (51, 73)
- 이중결제와 사전 고지 없는 약관 변경으로 월정액이 적용되지 않고 일 요금 12만원이 부과됨 (53, 92)
- 사용자가 배차를 거절하면 24시간 정지됨 (67)
- 대표 리뷰: "자동결재된걸 알텐데 현금낸 영수증을 보내라…이중결재 해결안해줌"(92). "약관 바꿔서 월정액 적용안시키고 일요금 12만원 부가, 사전고지도 없었음"(53).

### 출발·도착지 위치 오류 (관련 리뷰 6개)
- 지정한 출발지나 도착지가 바뀌거나 반영되지 않음 (69, 96)
- 앱의 위치와 기사 앱에 안내된 위치가 다름. 엉뚱한 곳으로 가서 요금이 늘어남 (48, 49, 56)
- GPS 위치 명칭이 부정확함. 추천경로가 사용자가 설정한 것처럼 표시됨 (68)
- 대표 리뷰: "지정한곳이 아닌 다른곳으로 가서 돈이 2배가 드는데 문의하면 전화를 끊음"(48). "다리밑을 찍었는데 기사한텐 다리위로 안내"(49).

### 로그인·앱 안정성 (관련 리뷰 5개)
- 접속할 때마다 로그인이 풀리고 로그아웃 메뉴도 찾기 어려움 (13, 40)
- 휴대폰 인증번호가 오지 않아 이용을 포기함 (38)
- 앱 연결이 자주 끊기고 갤럭시 기기와 연동이 안 됨 (23, 64)
- 대표 리뷰: "폰 번호 입력해도 인증번호 안옴 결국 버스타고 감"(38). "접속할 때마다 로그인이 풀려있나요"(13).

### 기사·차량 선택 및 탑승 중 기능 부족 (관련 리뷰 6개)
- 전기차 제외나 기사 선호(조용히 가기 등)를 설정할 수 없음 (59, 74, 90)
- 탑승 상태가 되면 기사에게 전화할 수 없음 (70)
- 승차거부를 신고할 방법이 없고 목적지 주소가 사전에 기사에게 보이지 않음 (71)
- 평가 팝업이 계속 떠서 번거로움 (43)
- 대표 리뷰: "전기차 제외 옵션 넣어주세요. 멀미 심하게 운전"(90). "승차거부 신고는 결제 완료한 택시만 가능"(71).

### 1. 일반 호출 배차 로직을 근거리·장시간 대기 우선으로 변경
① 바로 실행 · 심각도 상 · 난이도 중
- **개선 방법**: 가까운 택시를 우선 배차하고, 호출 후 오래 대기한 사용자의 순위를 높입니다. 반대 방향 차량과 먼 차량은 후보에서 제외합니다. 도착 예정 시간이 크게 늘어나면 자동으로 재배차하고 사용자에게 알립니다. 시외와 장거리 콜도 일반 호출에서 매칭되도록 합니다.
- **기대 효과**: 장시간 대기와 호출 포기, 앱 삭제가 줄어듭니다. 지표로는 일반 호출 성공률, 평균 배차 시간, 호출 후 이탈률, 도착 예정 시간 오차를 봅니다.
- **근거 리뷰**: 7, 8, 9, 22, 25, 32, 35, 37, 42, 62, 63, 65, 86, 89, 91, 97

### 2. 블루파트너스를 기본값에서 빼고 추가요금을 호출 전에 명확히 표시
① 바로 실행 · 심각도 상 · 난이도 중
- **개선 방법**: 호출 화면에서 일반 호출을 기본 선택으로 하고, 블루는 추가요금(1500~5000원)을 표시한 별도 선택지로 둡니다. 호출 확정 전에 최종 금액과 추가요금 내역을 한 번 더 보여줍니다. 일반 호출이 블루보다 불리하게 노출되지 않도록 합니다.
- **기대 효과**: 의도하지 않은 추가요금 결제와 앱이 블루를 강요한다는 불만이 줄어듭니다. 지표로는 블루 선택 후 즉시 취소율, 추가요금 관련 CS 문의 수, 일반 호출 비율을 봅니다.
- **근거 리뷰**: 3, 4, 10, 12, 34, 45, 72, 80, 83, 99

### 3. 추천경로를 빠른 경로 우선으로 바꾸고 실시간 교통·공사 반영
① 바로 실행 · 심각도 상 · 난이도 중
- **개선 방법**: 추천경로의 기본 기준을 최단 시간으로 두고, 실시간 교통과 공사 정보를 반영합니다. 큰길을 두고 골목으로 돌거나 반대 방향으로 유턴하는 경로는 후보에서 제외합니다. 기사 앱에도 같은 경로가 안내되도록 합니다.
- **기대 효과**: 돌아가는 경로 때문에 늘어나던 시간과 요금이 줄어듭니다. 지표로는 예상 대비 실제 소요 시간과 요금 오차, 경로 관련 불만 건수를 봅니다.
- **근거 리뷰**: 2, 6, 21, 29, 50, 81, 88, 93, 95

### 4. 출발·도착지가 앱과 기사 앱에서 동일하게 반영되도록 수정
① 바로 실행 · 심각도 상 · 난이도 중
- **개선 방법**: 사용자가 지정한 출발·도착 좌표를 임의로 바꾸지 않고, 기사 앱에도 같은 위치와 명칭을 표시합니다. 위치를 다시 지정하면 승차 위치도 즉시 갱신하고, GPS 장소명을 더 자세히 표시합니다. 추천경로와 사용자 지정 경로는 구분해서 표시합니다.
- **기대 효과**: 엉뚱한 곳 안내와 위치 임의 변경, 기사와의 불필요한 설명이 줄어듭니다. 지표로는 위치 불일치 CS 건수와 승차 위치 변경 후 취소율을 봅니다.
- **근거 리뷰**: 48, 49, 56, 68, 69, 96

### 5. 이중결제·환불 거부·약관 변경 대응 체계 정비
① 바로 실행 · 심각도 상 · 난이도 중
- **개선 방법**: 이중결제를 자동으로 감지해 환불하고, 현금 영수증 제출 없이 결제 내역으로 확인합니다. 기사 귀책 취소나 백투백 배차는 수수료를 면제합니다. 약관과 요금제가 바뀔 때는 앱 안에서 사전 고지하고 동의를 받습니다. 배차 거절에 따른 정지 기준도 완화합니다.
- **기대 효과**: 금전 피해와 환불 분쟁, 갑작스러운 요금 변경 불만이 줄어듭니다. 지표로는 환불·결제 관련 CS 건수와 환불 처리 소요 시간을 봅니다.
- **근거 리뷰**: 51, 53, 67, 73, 92

### 6. 경로 직접 선택과 경로별 예상요금 투명 표시
② 중장기 과제 · 심각도 상 · 난이도 상
- **개선 방법**: 사용자가 경로를 직접 고르거나 지정할 수 있게 하고, 경로 수도 늘립니다. 경로마다 예상 시간과 예상 요금을 표시하고, 처음 표시한 금액과 실제 결제 금액이 크게 다르면 사유를 보여줍니다.
- **기대 효과**: 추천경로가 요금을 올린다는 의심과 기사와의 경로 실랑이가 줄어듭니다. 지표로는 예상 요금 대비 실제 결제 금액 차이와 경로 변경 요청 수를 봅니다.
- **근거 리뷰**: 31, 33, 41, 44, 47

### 7. 블루 배차 시 운행 중이거나 먼 차량 제외
③ 여유 있을 때 · 심각도 중 · 난이도 중
- **개선 방법**: 유료 블루 호출에서는 승객이 탑승 중인 차량을 배차 후보에서 제외합니다. 예외가 불가피하면 예상 도착 시간을 미리 안내하고, 늦으면 무료로 취소할 수 있게 합니다.
- **기대 효과**: 추가요금을 내고도 15~30분 늦게 오는 불만이 줄어듭니다. 지표로는 블루 평균 도착 시간과 블루 배차 후 취소율을 봅니다.
- **근거 리뷰**: 19, 82, 87

### 8. 탑승 후 기사 연락·승차거부 신고·평가 팝업 개선
③ 여유 있을 때 · 심각도 중 · 난이도 중
- **개선 방법**: 탑승 상태에서도 기사에게 전화할 수 있는 버튼을 유지합니다. 결제 전에도 승차거부를 신고할 수 있게 하고, 도착지 주소를 기사에게 사전에 안내합니다. 기사 평가 팝업은 건너뛸 수 있게 하고 반복 노출을 줄입니다.
- **기대 효과**: 다른 사람이 택시를 잘못 탔을 때 기사에게 연락하지 못하는 문제와 신고 불가, 평가 팝업 피로가 줄어듭니다. 지표로는 승차거부 신고 건수와 평가 팝업 이탈률을 봅니다.
- **근거 리뷰**: 43, 70, 71

### 9. 로그인 유지와 로그아웃 메뉴 개선
③ 여유 있을 때 · 심각도 중 · 난이도 하
- **개선 방법**: 앱을 다시 열어도 로그인이 유지되도록 세션을 개선합니다. 설정 화면에서 로그아웃 메뉴를 찾기 쉽게 배치합니다.
- **기대 효과**: 접속할 때마다 다시 로그인하는 불편이 줄어듭니다. 지표로는 재로그인 빈도와 로그인 이탈률을 봅니다.
- **근거 리뷰**: 13, 40

### 10. 기사 취소 시 패널티·재배차·기사 차단 기능 도입
④ 보류 · 심각도 중 · 난이도 상

### 12. 전기차 제외와 기사 선호 옵션 추가
