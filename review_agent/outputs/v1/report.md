# 카카오T 앱 리뷰 분석 및 개선안 (리뷰 100건)

## 1. 개요
- 별점 분포: 1점이 압도적으로 많습니다. 5점은 약 7건이고, 대부분 짧은 인사말이나 칭찬입니다. 2~4점은 소수입니다.
- 의미 없는 리뷰(24, 27, 77~79)와 반어적인 리뷰(66: "좋아요, 11점"인데 별점은 1점)는 분석에서 제외하거나 가중치를 낮췄습니다.
- 아래 건수는 리뷰를 읽고 수동으로 센 대략적인 값입니다. 한 리뷰가 여러 주제에 걸치면 중복해서 셌습니다.

## 2. 주요 불만 주제 (빈도순)

### ① 추천경로 / 경로 안내 불신 (약 25건)
- 대표 리뷰: 2, 6, 21, 29, 31, 33, 41, 44, 47, 49, 50, 81, 88, 93, 95
- 빠른 길이 있는데도 막히거나 먼 길, 골목길로 안내한다는 불만이 가장 많습니다. 예상 요금과 실제 요금이 다르다는 불만도 같이 나옵니다. "예상 요금보다 1만 원 더 나온다"(44), "돈이 더 나오는 쪽으로 추천하는 것 같다"(41)는 의혹이 있습니다.
- 가장 먼 경로를 가장 싼 것처럼 표시한다는 지적이 있습니다(33).
- 사용자가 경로를 직접 지정할 수 없습니다(31, 33, 47). 기사와 경로를 두고 다투는 일이 생기고, 앱 안내를 따르지 않으면 기사가 패널티를 받는다는 점도 문제로 지적됩니다(95).
- 공사 구간이나 다리 위·아래 같은 진입 방향 오류가 있습니다(49, 95). 출발·도착 지점이 틀어지는 문제도 있습니다(48, 56, 68, 69, 96).

### ② 블루 파트너스 유도 / 추가요금에 대한 불신 (약 17건)
- 대표 리뷰: 1, 3, 4, 10, 12, 45, 72, 80, 82, 83, 87, 99, 34
- 블루가 목록 맨 위에 노출됩니다. 일반 택시를 눌렀는데 이용료가 추가되어 있었다는 불만이 있습니다(3, 4).
- 일반 호출은 잡히지 않고 블루만 바로 잡혀서, 일반 호출을 기사에게 일부러 전달하지 않는다고 의심하는 리뷰가 많습니다(10, 83, 99).
- 유료인데도 이미 승객이 타고 있는 차(백투백)가 배정되어 15~30분 늦게 옵니다(19, 51, 82, 87). 환불도 어렵습니다(51).

### ③ 배차 실패와 배차 품질 (약 25건)
- 대표 리뷰: 5, 7, 32, 42, 62, 83, 86, 91, 97
- 급할 때 30분~1시간 동안 배차가 안 됩니다. 비·명절·퇴근길·강남역에서는 더 심합니다.
- 배차가 잡혀도 먼 택시가 배정되고(8, 26, 35, 37), 도착 예정 시간이 4분에서 12분으로 바뀝니다(22). 반대 방향 차량이 배정되기도 합니다(65, 88).
- 기사가 단거리를 기피하거나(14) 시외 콜을 회피합니다(63). 아예 오지 않는 경우도 있습니다.

### ④ 기사의 일방적 취소 / 취소 패널티 불균형 (약 12건)
- 대표 리뷰: 1, 15, 26, 52, 55, 73, 75, 84
- 도착 1~2분 전에 기사가 취소하는데 고객에게는 보상이 없습니다. 기사가 일부러 돌면서 시간을 끌어 고객에게 취소 수수료를 물린다는 의심도 있습니다(52).
- 반대로 고객이 먼 배차를 취소하면 24시간 정지를 받습니다(67). 기사 귀책인데 고객이 수수료를 내는 일도 있습니다(73).
- 환불·CS 대응이 불만족스럽습니다(54, 55, 73, 92, 94).

### ⑤ 기사 서비스 품질과 안전 (약 8건)
- 대표 리뷰: 11, 16, 74, 85, 94
- 불친절, 과도한 대화, 요금 부당 청구, 미터기 시점 문제가 있습니다.
- 승차거부를 신고할 방법이 없습니다. 신고는 결제를 완료한 건만 가능합니다(71). 블루 호출 때 목적지가 미리 표시되지 않는 문제도 있습니다(71).

### ⑥ 기능 요청 (구체적 제안)
- 사용자가 경로를 직접 선택하거나 지정(31, 33, 47)
- 운행 중인 차량은 배차에서 제외하는 옵션(19, 82)
- 전기차 제외 옵션(59, 90)
- 기사 선호 설정(조용한 운행 등, 74)과 특정 기사 차단(84)
- 탑승 상태에서도 기사 통화 버튼 유지(70)
- 평점 팝업 제거 또는 간소화(43)
- 로그아웃 기능(40)과 로그인 유지(13)
- 카풀 재도입(25)
- 승차거부 신고 경로 확대(71)
- 일반 호출 우선 매칭 개선, 시외 호출 매칭 개선(63)

### ⑦ 기술적 오류 (약 6건)
- 로그인이 풀리고(13), 인증번호가 오지 않습니다(38).
- 앱이 자주 끊깁니다(23). GPS와 네트워크 오류도 있습니다(35).
- 갤럭시와 연동이 잘 안 됩니다(64). 이중 결제가 생기고 해결되지 않습니다(92).

### ⑧ 기타 서비스
- 바이크: 반납 구역이 좁거나 반납이 안 되고(18, 98), 배터리가 방전된 채 방치되며(100), 위약금이 부당하다는 불만이 있습니다(36, 61).
- 퀵: 기사 관리가 부실하고 취소 시 재접수 요금이 오르며 문의 응답이 느립니다(20, 55).
- 주차패스: 취소가 불가능하고 환불도 거절됩니다(54).
- 월정액: 사전 고지 없이 약관을 바꿨다는 불만이 있습니다(53).
- 펫택시: 요금이 비쌉니다(74).

## 3. 개선안 (우선순위)

### P0 – 신뢰 회복 (즉시)
1. **블루 UI와 요금 투명성**
   - 일반과 블루를 같은 비중으로 노출합니다. 블루를 기본값으로 선택하지 않습니다.
   - 호출 확정 전에 최종 요금(수수료 포함)을 명확히 보여줍니다.
   - 일반 호출이 기사에게 정상 전달되고 있는지 외부에 공개합니다. 필요하면 감사 결과나 배차 성공률 지표를 공개합니다.
   - 블루 배차 때는 승객 탑승 중인 차량(백투백)을 제외하거나, 사전에 안내하고 무료 취소를 보장합니다.
2. **경로·요금 신뢰도**
   - 추천경로의 선정 기준(최단 시간, 최단 거리, 최저 요금)을 라벨로 표시합니다.
   - 실시간 교통 정보와 공사 정보의 반영 품질을 점검합니다.
   - 사용자가 경로를 직접 선택하거나 경유지를 지정할 수 있게 합니다.
   - 예상 요금과 실제 요금의 차이가 크면 사유를 안내하고, 앱 안내 경로 때문에 생긴 추가 요금은 보상합니다.
3. **취소 정책의 형평성**
   - 기사 취소와 지연에 대한 패널티를 강화합니다.
   - 기사가 취소하면 같은 기사에게 다시 배차되지 않게 하고, 고객에게 우선 재배차 혜택이나 쿠폰을 줍니다.
   - 기사의 고의 지연으로 인한 고객 취소 수수료는 면제합니다.
   - 먼 배차를 고객이 취소할 때 "배차 거절"로 처벌하는 규정은 완화합니다. 예를 들어 도착 예정 시간이 일정 시간 이상이면 면책합니다.

### P1 – 배차 품질
1. 배차 거리와 ETA 상한을 두고, 오래 기다린 고객은 우선 배차합니다.
2. 목적지를 미리 공개해서 기사의 단거리·시외 기피를 줄입니다. 이와 함께 승차거부에 대한 패널티를 정비합니다.
3. 출발지·도착지가 정확히 반영되는지 검증합니다. 이를 위해 지점 명칭과 지도 핀을 더 정밀하게 하고, 기사 화면의 출발·도착 지점 표시와 고객 화면을 동기화합니다.
4. 비·명절 등 수요가 몰리는 때를 위한 사전 안내를 둡니다. 요금 변동 정책도 투명하게 공지합니다.

### P2 – 편의 기능
- 승차거부와 불친절 신고를 탑승 전·중에도 할 수 있게 하고, 신고 접수를 확인해 줍니다.
- 기사 선호 옵션(전기차 제외, 조용한 운행 등)과 특정 기사 차단 기능을 둡니다.
- 탑승 중에도 기사 통화 버튼을 유지합니다.
- 평점 팝업을 줄이고 건너뛰기를 허용합니다.
- 로그인 상태를 유지하고, 로그아웃과 계정 관리 기능을 제공합니다.
- 인증번호 발송, GPS, 네트워크 안정성을 개선합니다.

### P3 – 고객센터와 계열 서비스
- 이중 결제, 주차패스 취소, 월정액 약관 변경은 사전에 알리고 환불이 가능하도록 합니다.
- 바이크는 반납 구역, 배터리 관리, 위약금 기준을 개선합니다. 퀵은 기사 관리와 CS 응답 시간을 개선합니다.
- CS 응답에서 "기사 책임", "유의사항에 있다"는 식의 정형 답변을 줄입니다. 앱 책임인 부분은 인정하고 보상합니다.

## 4. 측정 지표(KPI) 제안
- 일반 호출 성공률과 평균 배차 시간(블루와 비교)
- 기사 취소율과 고객 취소율
- 실제 요금 대비 예상 요금 오차율
- 경로 관련 CS 문의 건수, 환불·분쟁 처리 시간
- 앱스토어 평점과 1점 리뷰 비중

## 5. 참고 사항
- 일부 의혹(블루 유도를 위한 일반 호출 차단, 요금을 더 받으려는 경로 추천)은 리뷰어의 추정입니다. 리뷰만으로는 사실 여부를 확인할 수 없습니다. 내부 데이터로 검증하고 그 결과를 사용자에게 투명하게 설명하는 것이 중요합니다.
- 욕설과 비하 표현이 섞인 리뷰(11, 14, 17 등)는 감정적 표현이 많습니다. 다만 그 안에 담긴 불만(기사 취소, 배차 지연)은 다른 리뷰에서도 반복되어 유효하다고 판단했습니다.
